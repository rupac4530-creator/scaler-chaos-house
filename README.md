# 🎪 Scaler: The Unofficial Chaos House

> *"Karna kuch aur chahta hu, kuch aur ho jata hai!"* — The official motto.

A fun, lighthearted parody and tribute website dedicated to our Scaler School of Technology experience, built with **pure HTML5 & CSS3** (zero JavaScript!).

Inspired by 80s-90s Memphis design, Bauhaus posters, and retro comic art — complete with bold borders, hard offset shadows, polka-dot patterns, and bright pop colors.

2. `mentors.html` — Meet the mentors hub + matrix comparison table
3. `icp.html` — ICP department, live lecture starter pack, and the 4 TA breakdown (You, Calculator, Google, WiFi)
4. `maths.html` — The Mathematics dimension, specs, and relatable Hinglish classroom dialogues
5. `webdev.html` — Web Dev department, hierarchy of suffering & 4-step web dev reality
6. `memes.html` — The meme zone, CSS typewriter animation & expectation vs reality cards
7. `survival.html` — 4 golden rules of Scaler survival + debugging flowchart
8. `gallery.html` — Hall of Chaos gallery with mentor portraits and real reference photos

## 🛠️ Tech Stack

- **HTML5**: Semantic tags, clean structure
- **CSS3**: Flexbox, CSS Grid, keyframe animations, custom properties, neo-brutalist styling
- **JavaScript**: None! Pure CSS magic.
